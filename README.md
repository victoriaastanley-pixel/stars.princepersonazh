# Твоя Аллея славы

База проекта перенесена 19 ноября 2026 года с https://stars.princepersonazh.ru/ по указанию владельца. Это существующий сайт, выбранный пользователем для дальнейшей разработки в этой папке и будущей публикации.

Репозиторий: https://github.com/victoriaastanley-pixel/stars.princepersonazh

Подготовка автоматической публикации GitHub → Vercel описана в `docs/DEPLOYMENT.md`. Настройки статического сайта находятся в `vercel.json`. Секреты для работы игры не нужны.

## Локальный запуск

В папке проекта выполните:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8765/ . Остановка сервера — Ctrl+C. Сборка и установка зависимостей не нужны.

## Файлы

- `index.html` — страница, фон SVG, правила и окно подарка.
- `style.css` — оформление и адаптация для небольших экранов.
- `game.js` — появление звёзд, счётчик, пауза и повтор игры.
- `logo.svg`, `cover-1.jpg`, `cover-2.jpg` — исходные изображения сайта.
- `font-0.ttf`–`font-7.ttf` — локальные шрифты Manrope и Oswald.
- `docs/IMPORT.md` — происхождение копии и результаты проверки.
- `docs/import-manifest.json` — список перенесённых ресурсов с SHA-256.

Приз открывается после трёх пойманных звёзд. Кнопка подарка ведёт в исходную папку Google Drive; содержимое самой методички в проект не скопировано.
