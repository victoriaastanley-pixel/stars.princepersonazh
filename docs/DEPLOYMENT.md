# GitHub → Vercel

## Подготовлено

- Основной репозиторий: https://github.com/victoriaastanley-pixel/stars.princepersonazh
- Основная ветка: `main`.
- `vercel.json` настраивает раздачу HTML/CSS/JS из корня без установки зависимостей и сборки.
- `.vercelignore` исключает документацию и локальные служебные файлы из загрузки сайта на Vercel.
- `.gitignore` исключает `.env`, локальные настройки Vercel и другие служебные файлы из обычного добавления в Git.
- Для текущего сайта пароли, токены и переменные окружения не нужны. Пользователь самостоятельно вводит любые данные входа в интерфейсе сервиса; агент не читает и не создаёт секреты.

## Что требуется для завершения подключения

19 ноября 2026 года API Vercel вернул 403 при запросе проектов: необходимо подтвердить доступ подключению к рабочему пространству `prince-cec8`. Подключение проекта и первая публикация пока не подтверждены. Повторно создавать проект до проверки существующих проектов нельзя.

После подтверждения доступа:

1. Проверить существующие проекты Vercel, чтобы не создать дубликат.
2. Подключить указанный репозиторий к проекту `stars-princepersonazh` (или использовать уже подключённый проект).
3. Выбрать Framework Preset `Other`, без команды сборки; каталог публикации — `.`. Эти настройки уже записаны в `vercel.json`.
4. Использовать `main` как Production Branch.
5. Выполнить первую публикацию и проверить игру по выданному адресу `vercel.app`.
6. Только после отдельного указания пользователя подключать существующий домен и менять DNS.

Если Vercel не показывает репозиторий, пользователь в интерфейсе GitHub разрешает приложению Vercel доступ именно к `stars.princepersonazh`. Пароли и коды входа вводятся только пользователем на странице сервиса.

После подключения встроенная интеграция Vercel автоматически публикует изменения `main`. Ветки и pull request используются для предпросмотра. GitHub Actions и дополнительные серверы для текущей игры не требуются.

## Тариф

Hobby ограничен личным или некоммерческим использованием. Коммерческий запуск требует отдельно решить вопрос тарифа; платные подписки автоматически не оформлять.
