# Перенос исходной базы

Дата: 19 ноября 2026 года.
Источник: https://stars.princepersonazh.ru/

Пользователь указал, что создал сайт в другом проекте, и выбрал его базой для работы в текущей папке. Скопированы доступные опубликованные файлы сайта: HTML, CSS, JavaScript, логотип, две обложки и восемь шрифтов. Это прямой перенос опубликованной версии, без перерисовки и замены игровой логики.

Исходный проект разработки и его история не найдены и не восстановлены: опубликованная версия доступна напрямую и достаточна для запуска этой статической игры. Серверная часть и настройки прежнего хостинга через публичный сайт недоступны.

## Единственное изменение в коде при переносе

Из конца HTML после подключения `game.js` удалён внедрённый Cloudflare скрипт проверки `/cdn-cgi/challenge-platform/`. Он относится к прежнему хостингу. Остальные файлы скопированы без изменений; исходный ответ HTML сохранён в `docs/source/index.served.html` для сравнения.

## Проверка локальной копии

Сайт запущен через локальный HTTP-сервер и проверен в браузере:

- Главная страница открывается, оформление и изображения отображаются.
- Правила открываются и закрываются.
- После нажатия на три разные звезды счётчик показывает «Поймано 3 из 3».
- Открывается окно подарка с двумя обложками и исходной ссылкой Google Drive.
- Повтор игры сбрасывает счётчик на ноль.
- Пауза переключает кнопку на «Продолжить».

Переход в Google Drive и доступность файлов методички не проверялись. Отдельная проверка на реальном телефоне не выполнялась.

Публикация и изменение существующего домена в рамках переноса не выполнялись.
